# سایت رزومه حسابداری

## ساختار پروژه
```
ali-accounting-site/
├─ index.html            ← ساختار و متن صفحه (فارسی/انگلیسی)
├─ css/
│  ├─ base.css           ← استایل اصلی، تم روشن/تاریک، ریسپانسیو
│  ├─ sections.css       ← بخش‌های جدید: مراحل، قالب‌ها، نظرات، پیش‌نمایش
│  └─ glass.css          ← تم Liquid Glass
├─ js/
│  ├─ data.js            ← لینک پرداخت، داده پیش‌نمایش جدول‌ها
│  └─ main.js            ← منطق: تم، زبان، منو، انیمیشن، پیش‌نمایش
└─ assets/
   ├─ img/logo.png       ← لوگو
   └─ docs/resume.pdf    ← فایل رزومه را اینجا بگذارید
```

## ویرایش سریع
| چه چیزی | کجا |
|---|---|
| لینک پرداخت هر فایل | `js/data.js` ← `PAY` |
| داده جدول پیش‌نمایش | `js/data.js` ← `PV` |
| قیمت‌ها | `index.html` ← `data-price` |
| آیدی بله، تلگرام، ایتا، لینکدین | `index.html` ← بخش contact (`USERNAME`) |
| شرکت‌های همکار و نظرات مشتریان | `index.html` (کامنت‌های HTML) |
| میزان شفافیت شیشه | `css/glass.css` ← `--gl` و `--gl2` |

## انتشار
کل پوشه را روی هاست آپلود کنید (یا با دوبار کلیک روی `index.html` محلی ببینید). فونت‌ها به اینترنت نیاز دارند.
